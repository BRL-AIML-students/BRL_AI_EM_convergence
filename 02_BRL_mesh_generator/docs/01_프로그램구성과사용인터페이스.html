입력·출력과 실행 경계

이 프로그램은 STEP·IGES·BREP의 CAD 표면을 1차 삼각형으로 분할하고, NAS 및 대응하는 단일 HTML 품질 보고서를 만듭니다. 입력한 solid도 표면만 삼각형으로 만들며 체적 요소는 생성하지 않습니다. STL과 이미 만들어진 메쉬를 이 변환기의 CAD 입력으로 받지 않습니다.

코드 사용의 기준 진입점은 convert_cad_to_nastran_surface_mesh.py입니다. 호출 프로세스에서는 설정과 결과를 처리하고, CAD마다 새 자식 프로세스에서 Gmsh를 초기화·종료합니다. 호출자가 이미 가진 Gmsh model의 변경이나 종료를 피하는 구조입니다.

MoM 코드는 생성된 좌표·삼각형 연결·PID·단위를 읽어 사용합니다. 메쉬 주파수는 호출자가 따로 지정하며 해석기의 주파수나 재료 변수를 자동으로 읽지 않습니다. 파장 분할 수와 형상 품질 기준은 MoM 정확도 보증이 아닙니다.

구현 위치: convert_cad_to_nastran_surface_mesh.py: convert_cad_to_nas, _worker · brl_mesh/surface_mesh_generation.py: run

실행 환경과 의존성

항목현재 구성과 사용 조건
Python지원 범위는 3.12 계열이며 .python-version은 3.12.14입니다. setup.ps1은 저장소 전용 환경을 준비합니다. 기존 MoM 환경과 별도로 사용할 수 있습니다.
고정 의존성Gmsh 4.15.2, NumPy 1.26.4, pyNastran 1.4.1. 설치 정의는 pyproject.toml과 uv.lock입니다.
호출 환경과 worker 환경호출측에는 어댑터와 brl_mesh의 설정 모듈이 함께 있어야 합니다. python_executable로 지정한 worker Python에는 고정 의존성과 네이티브 라이브러리가 필요합니다. 기본 worker는 호출 중인 sys.executable입니다.
설치 경로현재 Windows 경로 검사상 프로그램 루트는 ASCII 경로여야 합니다. CAD 입력 및 NAS 출력 경로의 한글은 별도 지원합니다. 이 제한은 설치 경로에 대한 것입니다.
쓰기 위치프로그램 루트의 .cache에 작업·크기장 조회·출력 검증용 임시 파일을 생성합니다. 설치 루트와 출력 폴더에 쓰기 권한이 필요합니다. 로컬에서 실행하고 검증된 최종 파일을 전달합니다.
배포 구성단일 Python 파일만 복사할 수 없습니다. 공통 brl_mesh 모듈과 의존성 정의를 함께 배치합니다. 최소 배포에는 이 세 문서를 포함하며 UI·기본 형상 구현·개발 계측은 제외합니다.

구현 위치: pyproject.toml · .python-version · setup.ps1 · tools/package_cad_to_nastran_mesh_converter.py

단일 변환 함수

convert_cad_to_nas(cad_path, nas_path, *, options=None, timeout=None,
                   python_executable=None, **overrides) -> ConversionResult
인자계약
cad_pathstr 또는 Path. 존재하는 .step/.stp/.iges/.igs/.brep. 상대 경로는 호출자의 현재 작업 디렉터리에서 절대 경로로 해석합니다.
nas_path입력과 다른 .nas 경로. 대응 보고서는 같은 폴더의 <stem>_quality.html입니다. 둘 중 하나라도 존재하면 덮어쓰지 않습니다.
optionsMapping 또는 None. 변환기용 평탄 옵션 object와 중첩 local/quality 설정을 전달합니다. 내부 Configuration 전체를 전달하는 인자가 아닙니다.
**overridesDEFAULT_OPTIONS의 이름별 keyword. options보다 우선하며 중첩 dict는 재귀 병합합니다. 저장된 원본 JSON·내부 Python 파일·DEFAULT_OPTIONS를 자동 변경하지 않습니다.
timeoutNone 또는 양의 유한수, 초. worker subprocess.run에 적용합니다. 초과는 ConversionError이며 이미 완료된 다른 작업을 취소하지 않습니다. 최종 전송까지 포함한 전체 API 실행시간 한도는 아닙니다.
python_executableworker Python 경로. None이면 sys.executable. 별도 가상환경 실행 파일을 지정할 수 있습니다.

성공하면 ConversionResult를 반환합니다. 실패하면 ConversionError를 발생시키고 exc.result에 구조화된 실패 정보를 담습니다. 일반 입력 오류는 status=error, worker에서 MeshBlocked로 판정한 실패는 status=blocked입니다.

구현 위치: convert_cad_to_nastran_surface_mesh.py: convert_cad_to_nas, ConversionError

인터페이스동작
ConversionJobcad_path, nas_path, options를 가집니다. options 기본 dict는 작업마다 별도 생성됩니다. Mapping job도 같은 세 키만 받으며 두 경로는 필수입니다.
convert_many작업을 순차 처리하는 iterator입니다. 실제 작업은 순회할 때 수행하며 CAD마다 별도 worker를 사용합니다. 전체 입력을 먼저 목록화하고 NAS·보고서 출력 경로 중복을 검사합니다. 병렬 처리가 아닙니다.
default_options / job.options작업별 options가 공통 default_options보다 우선합니다. 중첩 dict는 재귀 병합하고 배열은 교체합니다.
continue_on_errortrue이면 작업별 오류 결과도 yield하고 다음 작업으로 갑니다. false이면 해당 실패에서 ConversionError를 발생시킵니다. 전체 작업 목록·출력 중복·continue_on_error 형식의 사전 검증 오류는 작업별 결과 대신 ValueError가 될 수 있습니다.
jobs_from_directory확장자 기준으로 CAD를 정렬 수집합니다. recursive=true면 하위 폴더를 포함하고 출력 상대 폴더 구조를 보존합니다. 원래 파일 확장자 뒤에 .nas를 붙여 서로 다른 형식의 동일 stem 충돌을 피합니다. 실제 변환은 하지 않습니다.
load_mesh_optionsUTF-8 또는 UTF-8 BOM JSON object를 읽어 변환기 옵션과 병합·검증합니다. 중복 JSON 키와 NaN/Infinity를 거부합니다. 기본값을 합쳐 반환하며 CAD 존재·법선 등 형상 의존 검사는 변환 시 수행합니다. 크기 기준 없이 이 함수만 호출해도 필수 크기 검증에 실패할 수 있습니다.

설정의 구조와 적용 우선순위

외부 변환기 options와 내부 엔진 Configuration은 서로 다른 구조입니다. target_size·curvature_*·각 활성화 스위치는 외부 options에 있고, 내부에서는 mesh.target_size·mesh.wave·mesh.local·mesh.curvature 등으로 변환됩니다. 내부 Configuration의 schema_version·geometry·output_dir를 외부 options에 넣으면 미지원 키 오류입니다.

경로낮은 우선순위 → 높은 우선순위
단일 Python 호출DEFAULT_OPTIONS → options → 이름별 **overrides
일괄 Python 호출DEFAULT_OPTIONS → default_options → 각 job.options
CLI 공통 설정jobs 파일의 default_options → --options → 개별 CLI 옵션 → --quality의 지정 품질 키
CLI 작업별 설정공통 설정을 만든 뒤 각 job.options가 마지막에 덮어씁니다. 따라서 jobs의 개별 설정이 CLI 공통 설정보다 우선합니다.
규칙 내부local.short_edges/widths/gaps.enabled를 명시하면 상위 같은 이름의 bool/auto보다 우선합니다. local_size_fields_enabled=false는 전체 국소 적용을 중단합니다.

dict는 재귀 병합하고 배열·일반 값은 교체합니다. None/null은 모든 항목의 삭제 지시가 아닙니다. 허용된 항목에서만 값 없음으로 사용합니다. 알려지지 않은 키, 잘못된 자료형, 범위 위반은 strict parser가 거부합니다.

변환기는 활성 target_size 또는 활성 mesh_frequency_hz 중 하나를 요구합니다. 공통 엔진의 fallback_fraction은 외부 변환기에 노출된 옵션이 아니며 이 필수 조건을 대신하지 않습니다. 내부 엔진의 기본 단위와 외부 변환기의 기본 단위도 동일하다고 가정하지 않습니다.

전체 변수와 범위는 설정변수 빠른 참조에 모았습니다. 적용 결과는 반환값의 applied_options에서 내부 Configuration 형태로 확인합니다.

다른 언어에서 사용하는 CLI 계약

CLI는 Python 함수를 직접 import할 수 없는 호출자가 사용하는 동일 변환기의 입출력 경로입니다. 지원 인자와 응답 계약은 다음과 같습니다.

인자조건과 의미
--cad / --input-dir / --jobs세 입력 방식 중 정확히 하나. --cad에는 --nas, --input-dir에는 --output-dir가 필수입니다.
--nas / --output-dir / --recursive--cad와 --output-dir/--recursive는 함께 사용할 수 없습니다. --input-dir는 --nas와 함께 사용할 수 없습니다. --jobs는 세 인자 모두와 함께 사용할 수 없습니다.
--jobsdefault_options와 jobs 배열을 가진 JSON. 작업 경로는 해당 JSON의 폴더 기준입니다. options object를 대신 전달하는 파일이 아닙니다.
--options / --quality공통 변환기 options JSON과 별도 quality object JSON. --quality는 quality 키 자체로 다시 감싼 object가 아니라 지표 키를 직접 가진 object입니다.
--timeout / --stop-on-error작업별 worker 초 단위 한도 및 첫 실패에서 중단. 기본은 후속 작업 계속 처리.
--curvature / --short-edges / --widths / --gapson, off, auto. Python options의 true, false, "auto"로 변환합니다.
--target-size / --mesh-frequency-hz / --curvature-absolute-tolerance / --curvature-tolerance-ratio수치 옵션. 길이는 output_unit, 주파수는 Hz.
--target-size-enabled / --wavelength-sizing-enabled / --minimum-size-enabled / --local-size-fields-enabled / --local-curves-enabled / --local-boxes-enabled / --improvementon 또는 off.
--length-unit / --output-unit / --sheet-normal단위 m/cm/mm/um 및 sheet 부호 −1/+1.
그 밖의 변수모든 options 키가 CLI flag인 것은 아닙니다. 별도 flag가 없는 local 세부 규칙·품질 기준·곡률 표본 수 등은 --options나 Python options로 전달합니다. --_worker는 내부 프로토콜용입니다.

성공/작업 실패는 stdout에 작업당 한 줄 JSON으로 출력하며 status, reason과 결과 경로를 읽습니다. parser/입력 사전 오류에서는 축약 error JSON이 나올 수 있으므로 모든 필드가 항상 있다고 가정하지 않습니다. 종료 코드는 0=성공, 1=일반 오류, 2=차단이며, 일괄 실행에서 일반 오류가 하나라도 있으면 최종 코드는 1이 우선합니다.

구현 위치: convert_cad_to_nastran_surface_mesh.py: main

반환값과 품질 보고서

ConversionResult 필드의미
status / exit_codeok→0, error→1, blocked→2. status=ok는 파일 생성 완료이며 활성 품질 기준 전부 통과를 뜻하지 않습니다.
cad_path / requested_nas_path해석된 입력 CAD 경로와 요청 NAS 경로.
nas_path / quality_report_path성공 시 최종 NAS와 대응 HTML. 실패 결과에는 None이 기본입니다.
node_count / triangle_count최종 node 및 1차 triangle 수. 실패 시 기본 0.
applied_options자동 선택이 해소된 내부 설정. output_dir를 제외한 schema_version·geometry·length_unit·output_unit·mesh·improvement·generation·quality 구성.
warnings품질 기준 위반, auto에서 제외한 비지원 면·pole, 임시 정리 미완료 등의 메시지. 모든 경고가 작업 실패는 아닙니다.
reason실패 이유. 성공에서는 None.
quality_summaryelement_count, violating_count, metrics, nas_sha256, cad_sha256. metrics는 지표별 enabled·threshold·evaluated 및 활성 지표의 direction·minimum·mean·maximum·pass_percent·violating_count를 담습니다.
