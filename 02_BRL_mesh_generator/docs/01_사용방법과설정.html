BRL · TECHNICAL MANUAL · 01

사용방법과 설정

설치부터 CAD 변환·MoM 연동·모든 옵션 제어까지

정리일 2026-11-16 · Gmsh 4.15.2 · Python 3.12.14

처음 사용하는 순서
  1. 로컬 폴더에 설치한다.
  2. 포함된 원통 예제로 실행 환경을 확인한다.
  3. 설정 JSON에서 단위·메쉬 크기·평가 옵션을 지정한다.
  4. 성공한 NAS 경로만 MoM reader에 전달한다.

이 문서는 설치·실행·옵션의 기준 설명서다. 내부 Python 파일을 이해하려면 구조와 코드 해설, 검증 근거는 개발 검증 기록을 읽는다.

다른 컴퓨터에서 설치

지원 설치 대상은 기존 setup.ps1과 같은 Windows x64다. 배포 ZIP을 영문/숫자로 된 로컬 폴더 (예: C:\BRL_CAD_to_NAS)에 풀고 실행한다. 공백은 지원한다. 현재 Gmsh의 내부 field 파일 저장이 한글 설치 경로에서 실패하는 것을 확인했으므로 변환 전에 명확히 거부한다. CAD 입력과 NAS 출력 경로의 한글은 별도로 시험한다. 인터넷 연결이 필요한 최초 설치에서 Python 3.12.14와 고정 의존성(Gmsh 4.15.2, NumPy 1.26.4, pyNastran 1.4.1)을 전용 환경에 구성한다. 기존 MoM 환경은 변경하지 않는다. 다른 컴퓨터의 .venv, .tools, .cache를 복사하지 않는다.

powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1
.\run_cad_to_nastran_surface_mesh.bat --jobs .\examples\cad_to_nastran_conversion_jobs.json

배포본에는 최소 CAD 예제와 설명서가 들어 있다. 예제는 고정 경로에 NAS를 만들므로 반복 실행할 때는 새 출력 경로를 지정한다. 기존 파일을 자동 덮어쓰거나 재사용하지 않는다. ZIP 생성은 개발 컴퓨터에서 다음 명령으로 한다. ZIP도 기존 파일을 덮어쓰지 않는다.

.\.venv\Scripts\python.exe -B tools\package_cad_to_nastran_mesh_converter.py

기본 위치는 dist/CAD_to_NAS.zip이며, 엔진 소스·설치 스크립트·lockfile·연결 파일· 문서·예제만 포함한다. Git 이력, 테스트 산출물, 사용자 CAD와 NAS, 캐시, 환경은 제외한다. 설치 없는 EXE나 Linux/macOS 배포는 이번 검증 범위가 아니다.

명령행과 JSON Lines 계약

# 단일 CAD (상대 경로는 호출자의 현재 폴더 기준)
.\run_cad_to_nastran_surface_mesh.bat --cad "C:\CAD\part.step" --nas "C:\NAS\part.nas" --target-size 0.005

# 열린 sheet: CAD parameter normal의 양의 방향을 의도적으로 선택한 예
.\run_cad_to_nastran_surface_mesh.bat --cad "C:\CAD\sheet.step" --nas "C:\NAS\sheet.nas" --target-size 0.005 --sheet-normal 1

# 폴더 반복
.\run_cad_to_nastran_surface_mesh.bat --input-dir "C:\CAD" --output-dir "C:\NAS" --recursive --options settings.json

# CAD별 옵션/출력 경로
.\run_cad_to_nastran_surface_mesh.bat --jobs jobs.json --options settings.json

jobs JSON은 default_options와 jobs 배열로 구성하고, 각 job은 cad_path, nas_path, 선택적 options를 가진다. job 경로는 jobs JSON이 있는 폴더 기준이다. options에는 이 문서의 옵션만 넣는다. CLI에서 직접 명시한 공통 값은 options 파일보다 우선하며, 개별 job 옵션은 최종적으로 그보다 우선한다.

CLI toggle은 --curvature on|off|auto, --short-edges, --widths, --gaps이다. 목표 길이·파장·하한·국소장과 개선의 on/off 및 --quality는 전체 설정 설명서를 따른다. 나머지 모든 세부 값은 options JSON으로 지정할 수 있다. --timeout은 CAD별 초 단위다. 기본은 실패 후 계속 처리하며 --stop-on-error를 주면 첫 실패에서 멈춘다.

stdout은 CAD마다 JSON 한 줄이다. Gmsh의 native import 출력은 worker pipe에서 분리하며, 성공 응답의 status는 ok이고 nas_path, node_count, triangle_count, applied_options, warnings를 포함한다. 실패는 status=error 또는 blocked, nas_path=null, reason을 가진다. 잘못된 jobs/options 같은 전체 입력 오류는 최소 오류 object 한 줄을 반환한다. 실제 output_unit과 확정된 전체 엔진 설정은 applied_options에서 확인한다.

종료 코드: 전체 성공 0, 입력·실행·전송 오류 포함 1, 메시 검사 차단만 포함 2. CAD 하나의 실패는 다음 CAD의 Gmsh 상태나 설정을 오염시키지 않는다.

단일 함수 호출

from convert_cad_to_nastran_surface_mesh import convert_cad_to_nas, ConversionError

try:
    result = convert_cad_to_nas(
        cad_path=r"C:\CAD\antenna.step",
        nas_path=r"C:\NAS\antenna.nas",
        output_unit="m",
        target_size=0.005,
        curvature="auto",
        curvature_absolute_tolerance=0.0001,
        short_edges="auto",
        widths="auto",
        gaps=False,
        improvement=True,
        # 열린 sheet인 경우 설계 의도에 맞게 선택:
        # sheet_normal=1,
    )
    # 기존 MoM reader에 result.nas_path를 전달한다.
except ConversionError as exc:
    print(exc.result.status, exc.result.reason)

options={...}로 묶어서 넘길 수도 있다. 같은 옵션을 keyword로도 넘겼으면 keyword가 우선한다. 함수는 CAD마다 새 subprocess를 실행한다. 부모 프로세스에는 Gmsh를 import하지 않는다. 함수를 import하는 Python과 변환을 실행하는 Python이 다르면 다음처럼 명시할 수 있다.

result = convert_cad_to_nas(
    cad_path, nas_path, options=options,
    python_executable=r"C:\CAD_to_NAS\.venv\Scripts\python.exe",
    timeout=600,  # 선택사항: CAD 하나의 worker에 허용할 초
)

CAD·설정·모델 크기에 따라 시간과 메모리가 달라진다. 기본 timeout은 없으며, 임의의 요소 수 상한을 적용하지 않는다. 같은 Gmsh 세션을 여러 작업이 공유하지 않는다.

여러 CAD를 반복 처리

from convert_cad_to_nastran_surface_mesh import convert_many, jobs_from_directory

jobs = jobs_from_directory(r"C:\CAD", r"C:\NAS", recursive=True)
for result in convert_many(
    jobs,
    default_options={
        "length_unit": "mm", "output_unit": "m", "target_size": 0.005,
        "curvature": "auto", "curvature_tolerance_ratio": 0.02,
    },
    continue_on_error=True,
):
    if result.status == "ok":
        # 이 위치에서 기존 MoM 계산 함수를 호출할 수 있다.
        print(result.nas_path)
    else:
        print(result.cad_path, result.status, result.reason)

작업은 순차 실행되고 결과는 하나씩 반환된다. 한 결과를 받은 뒤 MoM 계산을 마치고 다음 반복으로 넘어가면 CAD 변환 → MoM → 다음 CAD 순서가 된다. MoM 자체의 함수나 명령을 변환기에 등록하지 않으며, 상대방이 자신의 코드에서 결과를 소비한다.

ConversionJob(cad_path, nas_path, options={...}) 또는 같은 키를 가진 dict 목록도 지원한다. 개별 옵션은 공통 옵션보다 우선하며, nested dict는 키별로 합친다. CAD별 nested 설정을 지우려면 해당 rule의 enabled=False 등 명시적 비활성화를 사용한다. 출력 경로가 중복되면 첫 변환 전에 일괄 작업을 거부한다. 폴더 방식은 하위 상대 경로와 확장자를 보존해 a.step.nas, a.igs.nas로 출력한다. CAD가 없는 폴더는 함수에서 빈 작업 목록을 반환하고 CLI에서는 오류로 처리한다.

전체 설정 파일과 옵션

수정할 파일은 examples/cad_to_nastran_mesh_options.json이다. Python 소스를 바꿀 필요 없이 ON/OFF와 숫자를 편집할 수 있다. true는 켜기, false는 끄기, null은 값 미지정, "auto"는 CAD를 확인해 적용 여부를 결정한다. JSON에는 주석을 넣지 않는다. 알 수 없는 키·중복 키·잘못된 타입·음수·NaN·Infinity는 오류다. 꺼진 기능에 저장한 값도 타입과 범위를 검사하므로, 켤 때 오타가 뒤늦게 드러나는 것을 방지한다.

1. 가장 먼저 바꿀 항목

목적 설정
CAD가 BREP이고 좌표가 mm "length_unit": "mm"
MoM reader에 m 단위 좌표 전달 "output_unit": "m"
약 5 mm 크기로 분할 요청 "target_size_enabled": true, "target_size": 0.005
메쉬용 10 GHz로 파장 분할 요청 "wavelength_sizing_enabled": true, "mesh_frequency_hz": 10000000000
전역 목표 길이만 사용 "wavelength_sizing_enabled": false
파장 조건만 사용 "target_size_enabled": false, 메쉬용 주파수는 양수로 지정
ICN 평가 끄기 "quality": {"icn_enabled": false}
AR 기준을 4로 변경 "quality": {"aspect_ratio_maximum": 4}
최소각 평가 끄기 "quality": {"minimum_angle_enabled": false}
radius ratio 0.6 이상 요청 "quality": {"radius_ratio_enabled": true, "radius_ratio_minimum": 0.6}
곡률 제어 끄기 "curvature": false
모든 국소 field 끄기 "local_size_fields_enabled": false (곡률 제어는 별도) 
.\run_cad_to_nastran_surface_mesh.bat --cad "C:\CAD\part.step" --nas "C:\NAS\part.nas" --options .\examples\cad_to_nastran_mesh_options.json

출력 파일이 이미 있으면 덮어쓰지 않는다. 새 경로로 실행한다. 열린 sheet는 설계자가 sheet_normal 또는 sheet_normals에 방향을 명시해야 한다.

2. 주파수와 단위

mesh_frequency_hz는 메쉬만을 위한 독립 입력이다. MoM의 주파수를 읽지 않는다. MoM 소스를 제공할 필요도 없다. 내부 엔진 JSON에서도 이름은 mesh.wave.mesh_frequency_hz이다. 이전 frequency_hz 키는 거부한다.

from convert_cad_to_nastran_surface_mesh import convert_cad_to_nas, load_mesh_options

mom_frequency_hz = 9.5e9       # 사용자의 MoM이 사용하는 변수
options = load_mesh_options("examples/cad_to_nastran_mesh_options.json")
options["mesh_frequency_hz"] = 12e9  # 메쉬에만 적용; MoM 변수와 독립
options["wavelength_sizing_enabled"] = True
result = convert_cad_to_nas(cad_path, nas_path, options=options)
# 사용자의 MoM reader에 result.nas_path를 전달하고 mom_frequency_hz로 해석한다.

모든 길이·좌표·box 범위·허용편차는 output_unit 기준이다. output_unit="m"이면 0.001은 1 mm다. length_unit은 BREP 원본 좌표 해석용이다. STEP/IGES 내장 단위는 importer가 읽으며 length_unit으로 덮어쓰지 않는다.

파장 조건은 양의 실수 εr·μr에서 매질 파장을 파장당 분할 수로 나눈 목표 길이다. 목표 길이와 파장 조건이 모두 켜지면 더 작은 길이를 사용한다. 적어도 하나의 활성 전역 입력이 필요하다. 연동에서는 CAD 크기로 주파수를 추정하거나 ONELAB의 1 GHz 기본값을 삽입하지 않는다. 요소 길이 요청은 실제 모든 edge 길이의 상한이나 EM 정확도 보증이 아니다.

3. 전역 크기와 개별 활성화

아래 기본값은 Python API에서 생략했을 때의 값이다. 편집용 예제는 실행할 수 있도록 length_unit="mm", target_size=0.001을 지정한다.

옵션 기본값 범위·역할
length_unit null m/cm/mm/um; BREP 필수
output_unit "m" m/cm/mm/um
target_size_enabled true 목표 길이 ON/OFF; 값은 보존
target_size null 양수 또는 null; 출력 단위
wavelength_sizing_enabled true 주파수 기반 길이 ON/OFF; 주파수가 null이면 미적용
mesh_frequency_hz null 양수 Hz 또는 null; MoM과 독립
elements_per_wavelength 10 양수; 파장당 분할 수
relative_permittivity 1 양의 실수 εr; 손실·분산 재료 모델이 아님
relative_permeability 1 양의 실수 μr
minimum_size_enabled true 하한 적용 ON/OFF; 값이 null이면 미적용
minimum_size null 양수 또는 null; 요구 크기와 충돌하면 차단

4. 크기장을 구성하는 국소 옵션

옵션 기본값 역할
local_size_fields_enabled true short_edges/widths/gaps/curves/boxes의 전체 스위치
short_edges "auto" true/false/auto; 짧은 CAD edge 길이에 따른 세분화
widths "auto" true/false/auto; 지원하는 평면의 폭에 따른 세분화
gaps false true/false/auto; 독립 surface 사이 거리 기반 세분화
local_curves_enabled true local.curves의 저장 목록 적용 여부
local_boxes_enabled true local.boxes의 저장 목록 적용 여부
local {} 아래 세부 설정 object

local_size_fields_enabled=false가 모든 국소 rule보다 우선한다. 전체 스위치가 켜져 있으면 local.short_edges/widths/gaps.enabled가 같은 이름의 단축 옵션보다 우선한다. 따라서 short_edges=false로 끄려면 nested local.short_edges.enabled=true를 남기지 않는다. 편집용 예제는 중복 스위치를 넣지 않고 단축 옵션으로 켜고 끄게 구성했다.

local 내부 키 기본값 값·의미
short_edges.enabled, widths.enabled, gaps.enabled 생략 bool; 명시하면 단축 옵션보다 우선
short_edges.divisions, widths.divisions, gaps.divisions 3 1 이상; 특징 길이를 나눌 분할 수
short_edges.entities 생략 CAD curve tag 목록; 명시적 빈 목록은 전체 선택
widths.entities 생략 CAD surface tag 목록; 명시적 빈 목록은 전체 선택
gaps.pairs [] 서로 다른 surface tag 쌍의 목록; 빈 목록은 자동 탐색
curves [] [{"entity": 1, "size": 0.0005}]; curve별 목표 길이
boxes [] [{"bounds": [xmin,ymin,zmin,xmax,ymax,zmax], "size": 0.0005}]
hold_distance 생략 0 이상; 특징 주위의 일정 크기 유지 거리; 생략 시 자동
transition_distance 생략 양수; 전역 크기로 돌아가는 전이 거리; 생략 시 자동
growth_rate 0.3 양수; 자동 전이 거리 계산에 사용
sampling_fraction 0.25 0 초과 0.5 이하; CAD 거리 field 표본 간격 비율

태그는 해당 CAD의 entity ID다. CAD를 바꾸면 유효성을 다시 확인한다. 중복 태그·잘못된 쌍· 역전된 box 범위는 오류다. 빈 수동 curves/boxes 목록은 해당 기능 미적용을 뜻한다. hold/transition을 자동으로 되돌리려면 키를 삭제한다(null을 넣지 않는다).

short_edges auto는 퇴화 OCC pole·seam을 제외해 대상 curve를 선택한다. 명시적인 entities는 그 선택을 대신한다. 실제 유한한 작은 edge는 제거하거나 병합하지 않는다. widths auto는 단일 loop·직선 경계·볼록 평면만 선택하고 제외된 면은 warnings로 알린다. widths=true로 지원하지 않는 면을 강제 지정하면 차단한다. gaps는 모든 좁은 목을 탐지하는 기능이 아니며 아래 보호 gap 검사와도 별개다.

5. 곡률·CAD 편차 제어

옵션 기본값 범위·역할
curvature "auto" true/false/auto; 곡면 또는 곡선 경계를 확인해 활성화
curvature_absolute_tolerance null 양수 또는 null; 출력 단위의 절대 표본 편차
curvature_relative_tolerance null 0 초과 1 미만 또는 null; entity 기준 상대 편차
curvature_tolerance_ratio 0.02 양수; 두 허용값 미지정 시 전역 목표 길이×비율
curvature_max_iterations 3 0 이상 정수; 편차 초과 시 추가 재생성 횟수
curvature_sampling_nodes 10 3 이상 정수; 피드백 표본 격자 설정
curvature_verification_nodes 19 sampling_nodes 이상 정수; 최종 표본 검사
curvature_feedback "entity" entity 또는 local; 면/곡선 전체 또는 위반 표본 주위 세분화

허용값 하나만 사용하려면 다른 하나를 null로 둔다. 둘 다 지정하면 더 엄격한 값을 적용한다. curvature=false는 값들을 보관하고 제어와 편차 검사를 끈다. 전체 국소 field 스위치를 꺼도 곡률 제어는 별도로 적용될 수 있다. 상대 허용값은 curve 길이·surface 면적 제곱근에 따르므로 CAD 면 분할에 영향을 받는다. 편차·하한·반복 한도 충돌을 숨겨서 완화하지 않는다. 이 검사는 유한 표본의 mesh→CAD 검사이며 연속 최대 편차·양방향 Hausdorff·EM 정확도를 보장하지 않는다.

quality object의 각 항목을 독립적으로 편집한다. 별도 파일 examples/mesh_quality_options.json에는 이 object만 들어 있다.

.\run_cad_to_nastran_surface_mesh.bat --cad "C:\CAD\part.step" --nas "C:\NAS\part.nas" --options .\examples\cad_to_nastran_mesh_options.json --quality .\examples\mesh_quality_options.json
quality 내부 키 기본값 범위·의미
icn_enabled true ICN 측정·기준 적용. false면 검사·개선·발행에서 Plugin 호출 생략
icn_minimum 0 0~1; ICN 하한. 활성 시 기본적인 양수 유효성도 별도 확인

radius_ratio_enabled false Gmsh gamma=2r/R 기준 적용 여부
radius_ratio_minimum 0.5 0~1; radius ratio 하한

AR은 최장 변 × 둘레 / (4√3 × 면적)이며 정삼각형에서 1이다. ICN과 radius ratio는 다른 지표다. AR·최소각을 임의의 ICN 하한으로 환산하지 않는다. AR/각도의 공통 형상 계산은 유효성 확인에 쓰일 수 있지만, 꺼진 지표는 합격·개선 후보 비악화 판정에 사용하지 않는다. 품질 색상 표시 선택은 이 합격 정책과 별개다. ONELAB에서 ICN 색상을 직접 요청하면 평가 스위치와 관계없이 해당 표시용 측정을 수행한다.

설정은 초기 검사·개선·재생성 판단·발행 직전 검사에 동일 적용된다. 개선은 활성 지표의 위반 요소 수를 줄이고 활성 지표·기하·크기·경계 보존 조건을 확인한다. 동률이면 기존처럼 활성 ICN의 개선을 사용하며, ICN이 꺼졌다면 활성 AR/각도/radius ratio의 개선을 사용한다. 모든 평가가 꺼지면 이 평가를 위한 node 이동을 시도하지 않는다.

이 설정은 위상·예상 경계·기준 법선·퇴화 요소·유한 좌표·CAD 보존·독립 NAS 읽기 검증을 해제하지 않는다. 평가를 끈 NAS는 꺼진 기준을 통과했다는 뜻이 아니다. 높은 기준값이 항상 실현 가능한 것도 아니며, 검사 통과가 MoM/RCS 수렴을 뜻하지도 않는다.

옵션 기본값 범위·역할

improvement=false로 해도 활성 평가는 수행한다. max_passes=0도 node 이동을 생략한다. quality_retry는 추가 메쉬 생성 요청이며 곡률의 편차 재생성 횟수와 별개다. sheet_normal=null은 방향 확인을 해제하는 옵션이 아니다. 닫힌 solid는 outward 기준을 사용하고 열린 sheet는 방향 정보 누락 시 차단한다.

8. 우선순위와 실제 적용값

Python: 기본값 → options dict → keyword override. 일괄 작업에서는 공통 options → 개별 job options 순서다. CLI: 기본값 → jobs.default_options → --options 파일 → 직접 CLI 값 → --quality 파일의 quality object → 개별 job options. object는 키별로 합치고 배열은 교체한다. --quality 파일에 없는 quality 키는 공통 options 값이 유지된다. curves/boxes를 비우려면 [], 중첩 rule을 끄려면 enabled=false를 명시한다.

CLI에서 --mesh-frequency-hz, --target-size, --curvature on|off|auto, --short-edges, --widths, --gaps를 지정할 수 있다. --target-size-enabled, --wavelength-sizing-enabled, --minimum-size-enabled, --local-size-fields-enabled, --local-curves-enabled, --local-boxes-enabled, --improvement는 on/off다. 나머지 세부 설정은 --options JSON 또는 Python options dict로 모두 지정할 수 있다.

결과의 applied_options는 꺼진 요구를 제거하고 CAD 자동 선택까지 확정한 내부 엔진 설정이다. 원본 편집 파일은 바꾸지 않는다. quality는 꺼진 지표의 flag와 저장 기준값도 보존한다. NAS provenance schema 4에도 실제 적용 설정이 들어간다. 생성 뒤 설정이 바뀌면 재생성을 요구하므로 다른 평가 기준으로 검사한 NAS를 그대로 발행하지 않는다.

MoM 소스를 공유하지 않는 연결

상대방은 자신의 언어의 subprocess API로 run_cad_to_nastran_surface_mesh.bat를 호출하고 종료를 기다린다. 종료 코드와 각 JSON의 status를 확인한 뒤 성공한 nas_path만 기존 MoM reader에 전달한다. 명령 문자열에 CAD 경로를 직접 합치기보다 인자 배열 또는 언어별 안전한 escaping을 사용한다. MoM이 별도 Python 버전을 사용하더라도 CLI가 자체 환경의 Python을 실행하므로 무방하다.

NAS는 GRID, CTRIA3, ENDDATA와 단위·설정 provenance 주석으로 이루어진 표면 메시다. PID는 현재 엔진처럼 CAD surface tag이며 재료번호로 자동 변환하지 않는다. ID가 연속이라는 가정, 주석 제거 요구, 단위, 열린 표면 지원 여부, RWG 연결·방향 조건은 상대방 reader와 합의한다. 이 형식은 완전한 구조해석용 material/property deck이 아니다. 법선 기준이 없는 열린 sheet는 surface tag를 포함한 오류를 반환하므로 sheet_normal 또는 sheet_normals를 지정한 뒤 재실행한다. 전 CAD에 임의의 +1을 기본 삽입하지 않는다.

파일 보호와 로컬 staging

설치 폴더 자체를 로컬에 둔다. CAD는 읽기 전용으로 읽으며 자동 분석 전후와 생성 중의 변경을 검사한다. 생성·검사·임시 NAS는 설치 폴더의 .cache/cad-to-nas 아래에서 수행한다. 검증된 NAS만 최종 위치로 전송하고 SHA-256을 대조한다. 목적지에 보고서·중간 mesh· sidecar를 생성하지 않는다. 결과 메타데이터는 함수/CLI 반환값에만 담는다.

최종 전송은 exclusive creation으로 기존 파일을 보호하며 정상적인 전송 실패에서는 자신이 만든 파일을 정리한다. 다른 드라이브/동기화 폴더로의 전송 전체가 원자적인 것은 아니다. 전송 중 파일이 보일 수 있으므로 파일 존재만으로 완료를 판단하지 말고 성공 응답을 기다린다. 강제 종료/정전으로 최종 경로에 부분 파일이 남으면 성공 응답이 없었던 해당 파일을 확인하고 새 출력 경로로 재실행한다. 자동 덮어쓰기·재개·기존 결과 재사용은 구현하지 않았다.

이 파일은 CSS·JavaScript·그림·MathML을 포함하는 독립 HTML입니다. 읽는 데 인터넷이나 별도 자산이 필요하지 않습니다. 코드·설정·다른 설명서 링크는 프로젝트 폴더 안에서 탐색할 때 사용합니다. 표와 큰 그림은 작은 화면에서 표 내부를 가로로 이동해 읽을 수 있습니다.
