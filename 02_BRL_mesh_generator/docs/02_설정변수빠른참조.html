빠른 참조 읽는 법

대상은 convert_cad_to_nastran_surface_mesh.py의 options 및 이름별 keyword override입니다. 아래 점 표기법은 중첩된 object의 위치를 나타냅니다. 점을 포함한 문자열 키를 그대로 전달하는 방식이 아닙니다.

기본값은 변환기의 DEFAULT_OPTIONS와 하위 설정 정의를 기준으로 합니다. 변수별 행에서 적용 조건과 값 변경의 영향을 확인하고 원리 링크로 상세 설명을 읽을 수 있습니다.

길이·좌표는 output_unit 기준입니다. 양수는 유한한 숫자를 뜻하며 bool은 숫자로 허용하지 않습니다. null 허용은 표에 명시한 항목에 한합니다. local 하위의 생략 가능한 숫자·배열에는 null을 넣지 말고 키를 생략합니다. target_size 또는 mesh_frequency_hz 중 하나는 값과 적용 스위치가 유효해야 합니다.

설정 적용 우선순위 · 품질 지표 상세 정의

브라우저 찾기(Ctrl+F)도 사용할 수 있습니다. 인쇄할 때는 전체 행을 표시합니다.

함께 확인할 적용 규칙

조건실제 처리
설정을 OFF로 저장대부분의 저장된 크기·곡률·국소·품질 값도 입력 유효성을 검사합니다. OFF를 잘못된 값 허용 수단으로 사용하지 않습니다. 형상 tag의 존재 등 CAD 의존 검사는 적용 경로에 따라 달라집니다.
국소 적용 우선순위전체 국소 스위치 → 수동 curve/box 스위치 → 개별 규칙. local 규칙에 명시한 enabled는 상위 auto/on/off보다 우선하지만 전체 OFF는 넘지 못합니다.
크기 기준 중첩전역 및 국소 요청을 더 작은 길이 쪽으로 결합하고, 곡률 callback도 기존 요청과 작은 값을 택합니다.
최소 크기 충돌필수 요청이 사용자 하한보다 작으면 충돌입니다. 필요한 작은 요청을 몰래 하한으로 키우지 않습니다.
품질 하한·상한경계값과 같은 수치는 통과입니다. 활성 지표의 기준 위반은 경고와 보고서로 남으며 NAS를 차단하지 않습니다.
필수 검사 실패퇴화·연결·법선·CAD 보존·활성 필수 측정·NAS 독립 검증 오류는 출력 차단 대상입니다. 품질 지표 OFF로 해제하지 않습니다.
