CAD 읽기·단위·경계 방향

단위 변환

STEP·IGES는 파일의 단위를 읽고 OCC의 target unit을 output_unit으로 지정합니다. BREP는 단위 정보에 의존하지 않고 사용자가 지정한 length_unit과 output_unit의 비율을 OCC compound 읽기에 적용합니다. entity tag를 붙인 뒤 solid만 따로 축척하여 sheet나 curve를 빠뜨리는 처리를 피합니다. IGES는 현재 Gmsh/OCC 단위표 초기화를 위해 임시 model에서 읽은 뒤 버리고, target unit으로 다시 읽습니다.

목표 길이, 국소 size, 거리·편차, 박스 좌표, protected_gap은 이미 output_unit 기준 값입니다. length_unit으로 이 값들을 다시 환산하지 않습니다.

entity·component·PID

OCC synchronize 뒤 모든 surface를 열거해 surface tag를 PID로 대응시키고 면마다 Physical Surface를 만듭니다. curve를 공유하는 surface들을 연결 성분으로 묶습니다. solid 소유 surface와 소유 solid가 없는 sheet를 구분합니다. 이 연결과 경계 정보는 생성 이전 CAD에서 얻는 참조입니다.

solid는 CAD의 안/밖 판정으로 바깥 방향을 확인합니다. sheet는 CAD parameter normal에 대한 ±1 기준을 호출자가 지정해야 합니다. sheet_normals가 특정 면에서 sheet_normal보다 우선합니다. +1은 좌표계의 +z나 항상 바깥쪽을 뜻하지 않습니다. 방향이 없는 sheet와 여러 solid가 공유하여 바깥이 모호한 면은 정상 방향으로 추정하지 않습니다.

생성 참조 보존

fingerprint는 model·entity tag·종류·boundary·bounding box·CAD 길이/면적/체적과 관성 정보·Physical Group 등을 묶습니다. 원본 해시와 CAD 참조를 현재 상태에 대조합니다. CAD를 자동으로 봉합하거나 분리된 gap을 병합해 입력 의미를 바꾸는 별도 복구 단계는 이 경로에 없습니다.

전역 크기와 파장 기준

크기장 h(x)는 위치에 요청하는 대표 요소 길이입니다. 사용자가 target_size를 주면 전역 후보가 되고, mesh_frequency_hz를 주면 파장 기준 후보를 계산합니다. f는 독립 메쉬 주파수(Hz), N은 elements_per_wavelength, εr·μr은 양의 상대 물성, c는 299792458 m/s, u는 출력 단위 하나가 몇 m인지 나타내는 값입니다.

hwave=cfNεrμru
hg=min(htarget,hwave)

값이 있고 스위치가 켜진 후보만 비교합니다. 같은 조건에서 f, N 또는 상대 물성을 키우면 파장 기반 요청 길이는 감소합니다. 전역 크기를 그대로 두더라도 다른 국소·곡률 요청이 더 작으면 그 영역은 더 세분화될 수 있습니다.

외부 변환기는 target_size 또는 mesh_frequency_hz 중 적어도 하나를 활성 값으로 요구합니다. 내부 공통 엔진의 resolve_global에는 두 후보가 없을 때 CAD bounding box 대각 길이 × fallback_fraction(기본 0.1)을 쓰는 분기가 있지만, 이것은 변환기 options에 노출된 자동 대체 경로가 아닙니다.

현재 파장 산정은 양의 실수 상대 물성을 사용하는 길이 기준입니다. 손실·분산·복소 매질·표면파나 전류 특이점까지 반영한 EM 오차 추정기가 아닙니다. 파장당 분할 수의 기본값은 메쉬 설정이며 관측량 수렴을 대신하지 않습니다.

구현 위치: brl_mesh/mesh_size_fields.py: resolve_global · convert_cad_to_nastran_surface_mesh.py: _options, _resolve_configuration

CAD 특징을 길이 요청으로 바꾸는 규칙

각 규칙은 측정 길이를 divisions로 나누어 특징 요청 크기를 만듭니다. 전역 크기보다 충분히 작을 때만 세분화 특징으로 남깁니다. 더 큰 수동 크기를 넣어 특정 영역만 전역보다 거칠게 만드는 기능은 아닙니다.

hfeature=ℓD
규칙측정과 대상제한과 auto 처리
short_edgesOCC curve의 전체 길이/분할 수. 표면 경계 non-seam curve를 대상으로 삼고 주변 거리장으로 전파합니다.상위 auto이고 entities 키를 생략하면 변환기가 seam과 OCC 퇴화 pole을 제외한 대상을 선별합니다. 명시 seam은 거부합니다. 길이가 0인 pole을 유한한 특징으로 세분화하지 않습니다.
widths단일 loop·직선 경계·볼록 평면 polygon의 최소 지지선 폭. 회전된 좌표에서도 좁은 폭을 측정하며 면 전체에 작은 크기를 제한 적용합니다.점들을 SVD로 평면 좌표화하고, 각 경계 edge의 수직 방향 투영 폭 중 최소를 계산합니다. 곡면·곡선 경계·hole·비볼록 neck은 일반 폭 추정 대상이 아닙니다. auto는 width_unsupported 면을 제외해 경고하고, 명시 사용 시 비지원 대상을 정상 처리로 숨기지 않습니다.
gaps독립 surface 쌍의 OCC 최소 거리/분할 수. bounding box 거리로 먼 쌍을 먼저 제외하고 최소 거리 및 반환 endpoint 일치를 확인합니다.pairs가 비면 독립 연결 성분의 후보를 찾으며 같은 solid 소유 shell과 공유 연결은 제외합니다. 0 또는 수치적으로 모호한 접촉을 자동 병합하지 않습니다. 최소 연결선과 겹치는 범위의 보수적인 박스를 만들며 임의 곡면 사이의 모든 위치별 gap 폭 지도를 계산하지 않습니다.
local.curves지정 curve의 수동 size.실제 CAD curve tag가 필요합니다. 중복 entity는 입력 오류입니다.
local.boxes지정 공간 bounds의 수동 size.좌표는 output_unit 기준입니다. 표면 메쉬가 박스와 만나는 영역의 요청을 정하며 별도 CAD를 생성하지 않습니다.

상위 short_edges·widths·gaps는 true/false/auto이고 local 규칙의 enabled는 bool입니다. enabled를 명시하면 상위 선택보다 우선합니다. auto의 선별은 entities 키를 생략한 경우이며, 빈 entities를 명시하는 것과 같지 않습니다. 엔진에서 활성 규칙의 entities가 빈 배열이면 전체 후보를 뜻하므로 widths에 빈 배열을 명시하면 비지원 면도 검사 대상이 될 수 있습니다.

구현 위치: brl_mesh/cad_feature_size_rules.py: discover, polygon_width, independent_pairs · convert_cad_to_nastran_surface_mesh.py: _resolve_configuration

국소 크기장의 구성과 결합

작은 길이를 유지하고 전역 길이로 전이

특징 크기를 hf, 전역 크기를 hg, 특징까지 거리를 d라고 둡니다. hold_distance인 a는 작은 크기를 유지할 거리이며 생략 시 hf입니다. transition_distance인 T는 전역 크기로 돌아가는 구간 길이이며, 직접 지정하지 않으면 growth_rate인 g로 계산합니다.

T=hg−hfg
t=clip(d−aT,0,1),h(d)=hf+t(hg−hf)

growth_rate는 인접 요소의 실제 크기비 상한이 아닙니다. 같은 크기 차이에서 g가 작을수록 T가 길어집니다. 명시 transition_distance가 있으면 그 값이 우선하며, 0이나 부동소수점으로 구별할 수 없는 전이는 오류입니다.

실제 Gmsh field 구성

특징field 연결의미
짧은 edge·수동 curveDistance → Thresholdcurve와 endpoint를 거리장 대상으로 삼고 hold/transition에 맞춰 SizeMin→SizeMax를 선형 전이합니다. Sigmoid=0, StopAtDistMax=0.
폭 규칙Distance → Threshold + MathEval → Restrict경계 주변 거리장과 함께 해당 surface 및 경계에 작은 상수 크기를 제한 적용하여 좁은 면의 내부도 반영합니다.
gap·수동 boxBox원래 bounds를 hold_distance만큼 각 축으로 확장하고 Thickness에 transition_distance를 넣습니다. VIn=특징 크기, VOut=전역 크기입니다.
전체 결합MathEval(전역 크기) + 각 leaf → Min모든 요청 중 작은 값을 background field로 사용합니다. 국소 특징이 없으면 field 없이 전역 크기 옵션을 사용합니다.

MeshSizeFromPoints·MeshSizeFromCurvature·MeshSizeExtendFromBoundary는 0으로 두고 MeshSizeFactor=1로 사용합니다. 여기서 곡률 설정을 끈 Gmsh 기본 옵션과 프로그램의 곡률 callback은 다른 경로입니다. 프로그램의 곡률 제어는 활성일 때 callback에서 기존 lc와 곡률 요청 중 작은 값을 반환합니다.

요청 길이와 실제 길이 비교

개선 보호에 쓰는 nominal_sizes는 CAD까지의 연속 거리와 동일한 설계 전이를 계산한 값입니다. Gmsh가 표본으로 구성한 field 평가기를 그대로 읽어 반환하는 함수가 아닙니다. 박스 거리는 확장 박스 밖의 유클리드 거리로 평가하고, 폭 규칙 surface에는 작은 크기를 직접 적용합니다.

local_edge_ratio는 각 삼각형 edge 중점에서 nominal 크기를 구하고 실제 edge 길이/요청 길이의 최댓값을 계산합니다. 전역 edge_max_to_target도 실제 최대 edge/전역 크기입니다. 이 비율을 1로 강제하는 독립 출력 차단 조건은 없으며 개선으로 기존 크기 준수 상태를 악화시키지 않도록 비교합니다.

거리장 표본과 CAD 편차 표본

곡선 Distance field의 표본 수

sampling_fraction인 α는 거리장의 곡선 표본 간격을 결정합니다. a가 양수일 때 다음 식을 쓰며 a=0이면 세 번째 후보로 hf를 사용합니다. 이 표본은 곡률 편차 검증 격자와 별개입니다.

s=α·min(hf,T,a)

초기 표본 수는 관련 curve의 최대 OCC 길이와 s로 계산하여 최소 8개로 시작합니다. parameter를 등간격으로 나눈 점들을 실제 CAD에 평가하고, 모든 chord가 s 이하인지와 chord 합이 CAD 길이의 99.9% 이상인지 확인합니다. 부족하면 표본 수를 두 배로 늘립니다. parameter 공간의 같은 간격이 실제 길이의 같은 간격이라고 가정하지 않습니다. 추가 parameter를 표현할 수 없는데도 조건이 부족하면 sampling_precision_conflict로 차단합니다.

line·triangle의 편차 표본

곡률 표본 설정의 n은 격자 해상도입니다. line은 두 끝점을 포함한 n개, triangle은 barycentric 좌표의 삼각 격자로 n(n+1)/2개의 점을 사용합니다. sampling_nodes=10은 삼각형당 55점, verification_nodes=19는 190점에 해당합니다. 별도 검증 해상도는 생성 확인 해상도 이상이어야 합니다.

Nline=n,Ntriangle=n(n+1)2

직선 요소 위 표본 좌표를 CAD curve/surface로 투영하여 거리를 재고 요소별 최댓값을 원래 element ID와 대응시킵니다. surface 투영은 trim 내부 여부와 parameter→좌표 복원 일치도 확인합니다. 표본은 batch로 처리하고 큰 n에서도 격자 일부를 생략하는 대신 작업 배열을 나눕니다.

표본 최대 편차는 검사한 점들에서의 최대값입니다. 연속 CAD 전체에 대한 Hausdorff 거리 상한이나 모든 위치의 최대 오차 증명은 아닙니다. 표본 수를 늘리면 확인 범위가 촘촘해지지만 그 자체로 EM 해의 수렴을 증명하지 않습니다.

곡률 기반 초기 크기와 허용 편차

곡률 활성화와 entity별 허용치

curvature=auto이면 평면이 아닌 surface 또는 길이가 양수인 직선 아닌 curve가 있는지 검사해 적용합니다. true는 명시 활성화, false는 비활성화입니다. local_size_fields_enabled와 독립입니다. 절대·상대 허용치를 모두 지정하지 않았다면 전역 크기 × curvature_tolerance_ratio를 절대 허용치로 만듭니다.

δentity=min(δabs,ηrelLentity)

지정된 후보만 비교합니다. 상대 기준의 Lentity는 curve에서는 CAD 길이, surface에서는 CAD 면적의 제곱근입니다. 따라서 같은 상대 비율도 entity마다 다른 절대 허용치를 만듭니다. δ가 CAD 좌표 규모의 부동소수점 정밀도 이하이면 허용 가능한 요청으로 받아들이지 않습니다.

국소 곡률로 길이 추정

curve는 국소 곡률의 절댓값 k, surface는 두 주곡률 절댓값의 큰 쪽을 사용합니다. k=0이면 전역 크기를 반환합니다. δk가 1 미만인 일반 분기에서는 다음 초기 추정식을 씁니다.

hcurve=min(hg,8δk−4δ2)
hsurface=min(hg,6δk)

curve 식은 반지름 1/k의 원호를 chord로 표현할 때의 sagitta 관계에 해당합니다. surface 식은 곡률과 중심 편차의 국소 추정으로 쓰며 이후 실제 CAD 표본 검사로 확인합니다. δk가 1 이상이면 min(hg, δ)를 사용해 아주 작은 반지름·pole에서 길이를 무조건 0으로 축소하지 않습니다.

surface의 주곡률 방향이 유효하지 않은 pole에서는 parameter 경계 안쪽으로 조금 이동해 다시 조회하고, 유효성을 끝내 확인하지 못하면 차단합니다. point와 curve 경계에서도 인접 curve·surface의 곡률 요청 중 작은 값을 반영합니다.

최소 크기·좌표 정밀도와 충돌

minimum_size는 더 작은 필수 요청을 조용히 무시하기 위한 값이 아닙니다. 전역 및 특징 요청이 명시 하한보다 작으면 minimum_size_conflict이며 곡률 callback 요청이 하한보다 작으면 curvature_minimum_conflict입니다. Gmsh MeshSizeMin으로 요청을 몰래 키운 뒤 성공 처리하지 않습니다.

사용자 하한이 없고 곡률도 없으면 전역/특징 요청 중 최소값을 Gmsh 하한으로 사용합니다. 곡률이 켜졌고 사용자 하한이 없으면 앞으로 더 작은 곡률 요청이 나올 수 있으므로 좌표 정밀도 규모의 수치적 하한을 사용합니다. 좌표의 절댓값이 매우 크고 요구 길이가 매우 작으면 필요한 차이를 표현할 수 있는지도 검사합니다.

좌표 원점에서 멀리 떨어진 아주 작은 형상에서는 단순히 target_size를 줄이는 것만으로 요청을 표현할 수 없습니다. 여기서 정밀도 충돌은 형상 품질 기준 위반 경고와 다른 생성 차단 조건입니다.

표면 삼각형 생성 알고리즘

CAD 편차 피드백과 메쉬 재생성

초기 생성 뒤 sampling_nodes 해상도로 편차를 측정합니다. 비율이 1+1e−10 이하이고 verification_nodes가 다르면 검증 격자로 다시 측정합니다. 검증까지 통과하면 반복을 끝냅니다. 위반이면 보정 요청을 갱신하고 gmsh.model.mesh.clear() 후 전체 메쉬를 다시 생성합니다. 기존 삼각형 일부만 잘라 연결을 유지하는 국소 refinement가 아닙니다.

아래 ρ와 β는 보정 대상마다 계산합니다. entity 모드는 해당 entity의 최대 편차비, local patch는 위반 요소의 편차비를 사용합니다. 전체 메쉬에서 가장 큰 비율 하나를 모든 면에 똑같이 적용하지 않습니다.

ρ=max(dsampleδentity),β=min(0.7,0.7ρ)
피드백 모드크기 요청 보정
entity위반 curve 또는 surface의 scale을 β만큼 곱해 entity 전체의 곡률 요청을 줄입니다.
localsurface에서 위반 요소의 최대 편차 투영점을 중심으로 patch를 만듭니다. 반경은 해당 요소 직경의 4배이며 중심에서 반경 절반까지 완전 축소, 바깥 절반은 매끄럽게 전이합니다. curve는 entity 단위 축소를 유지합니다.
patch 중첩한 반복 안의 patch는 가장 강한 축소를 택하고 반복 간에는 scale을 곱합니다. 같은 위치의 반복 위반이 이전 축소값에 머무르지 않게 합니다.
happlied=δ0+(hrequired−δ0)s,δ0=min(hrequired,δ)

s는 entity scale과 활성 local patch scale의 곱입니다. 처음에는 1이고 반복에 따라 감소합니다. 위 식은 작은 반지름의 절대 해상도를 불필요하게 0으로 보내지 않으면서 초기 곡률 요청을 축소합니다. 표본·CAD/경계 fingerprint와 대응하지 않는 오래된 feedback은 적용하지 않습니다.

max_iterations는 초기 생성 이후의 보정 재생성 횟수 상한입니다. 한도에 도달했는데 편차가 남으면 curvature_iteration_limit로 차단합니다. callback 안의 Python 예외는 기록한 뒤 생성 호출을 빠져나와 차단하므로 잘못된 숫자를 성공으로 넘기지 않습니다.

삼각형 품질 지표의 정의와 평가

품질 지표는 요소의 형상을 서로 다른 관점에서 봅니다. 각 지표의 enabled와 threshold는 독립이며 다른 지표의 기준으로 환산하지 않습니다. 기준과 같은 값은 통과입니다. 어떤 지표도 CAD 경계·법선·연결성 검사나 EM 관측량의 수렴 검사를 대신하지 않습니다.

AR과 최소각: 좌표에서 직접 계산

삼각형 변 길이를 a, b, c, 둘레를 P, 면적을 A, 가장 긴 변을 Lmax라고 둡니다. 프로그램의 AR은 Lmax/Lmin이 아니라 다음 정의입니다. r은 내접원 반지름입니다.

A=‖(x2−x1)×(x3−x1)‖2
AR=LmaxP43A=Lmax3r

정삼각형의 AR은 1이며 길쭉하거나 퇴화할수록 커집니다. aspect_ratio_maximum은 상한이고 기본 3입니다. 이 정의를 Gmsh의 다른 aspect ratio나 ICN의 역수와 동일시하지 않습니다.

θi=atan2(‖ai×bi‖,ai·bi),θmin=min(θ1,θ2,θ3)

ai와 bi는 꼭짓점 i에서 나가는 두 edge 벡터입니다. atan2의 결과를 도 단위로 바꿔 가장 작은 각을 사용합니다. 정삼각형의 최소각은 60°이고 기본 하한은 20°입니다. 계산은 요소별로 좌표를 평행이동·정규화하여 큰 절대 좌표나 서로 다른 component 규모의 영향을 줄입니다. 퇴화·비유한 기하 판정은 품질 스위치와 별개입니다.

ICN: 요소 변환의 조건

ICN은 Inverse Condition Number 계열의 요소 형상 지표입니다. 삼각형의 기준 좌표를 실제 요소의 접평면 좌표로 보내는 Jacobian 변환이 한 방향을 심하게 늘리고 다른 방향을 압축하면 형상이 나빠집니다. 정규화된 좋은 형상은 1에 가깝고 퇴화 방향으로 갈수록 0에 가까워집니다. 이는 좌표 변환의 조건에 대한 형상 측정이며 MoM 전체 임피던스 행렬의 condition number를 직접 계산한 값은 아닙니다.

현재 구현은 AnalyseMeshQuality의 ICNMeasure로 측정한 값을 받습니다. 자체 condition number 수식을 계산해 Plugin 결과 대신 사용하지 않습니다. icn_minimum 기본 0.0은 추가 양의 하한을 요구하지 않는 설정이지만 활성 측정 결과는 모든 요소에서 유한한 양수여야 합니다.

IGE: 형상과 기울기 오차의 관계

IGE는 Inverse Gradient Error 계열의 형상 지표입니다. 유한요소 기준 좌표의 기울기를 실제 요소에 옮길 때 변환 Jacobian의 역행렬이 개입하므로 찌그러진 요소는 기울기 오차를 증폭시킬 수 있습니다. Gmsh는 이 성질에 관련된 정규화된 형상 척도를 제공합니다. 이는 현재 프로그램에서 FE 해를 계산했다는 뜻이 아니며 MoM 전류·원거리장 오차의 추정값도 아닙니다.

현재 구현은 AnalyseMeshQuality의 IGEMeasure만 켠 별도 호출로 받습니다. ige_enabled 기본 false, ige_minimum 기본 0.0입니다. Gamma나 프로그램 AR의 역수로 대신하지 않습니다. 정확한 정규화와 평가식은 Gmsh 구현의 책임이며 여기서는 Plugin 지표 이름·값을 그대로 유지합니다.

Radius Ratio: 내접원과 외접원

q=2rR,r=2AP,R=abc4A

위 식은 현재 1차 삼각형에서 정삼각형을 1로 정규화한 관계입니다. 실제 측정은 Gmsh getElementQualities(element_ids, "gamma") 결과를 사용하며 위 식을 자체 계산하여 대체하지 않습니다. r/R를 정규화하지 않은 값, IGE, AR 역수와 혼동하지 않습니다. 값이 작을수록 길쭉하거나 퇴화한 형상이고 radius_ratio_minimum 기본 0.5는 하한입니다.

Plugin/API 결과를 현재 요소에 대응시키기

ICN과 IGE는 각각 DimensionOfElements=2, Recompute=1, CreateView=1, JacobianDeterminant=0으로 호출하고 요청한 지표 하나만 켭니다. 이번에 만들어진 단일 model view의 scalar 결과를 읽고 element ID 전체 집합·중복·값 개수·유한성·양수·상한 범위를 검사합니다. 읽은 값은 현재 mesh.element_ids 순서로 재배열합니다. 기존 view와 visibility는 보존하고 이번 view만 정리합니다.

Radius Ratio API도 요소 수와 배열 대응, 유한한 양수 및 1 상한을 확인합니다. Plugin/API 측정 실패·누락은 지표 기준 미달과 달리 출력 차단입니다. AR·최소각은 내부 검사에 필요한 계산이 남아 있어 enabled=false를 모든 형상 계산의 생략으로 해석하지 않습니다.

ICN·IGE의 일반 의미 및 API 명칭은 Gmsh 4.15.2 Plugin 문서와 공식 품질 지표 설명에서 확인할 수 있습니다. 일반 정의와 이 프로그램의 측정 경로·허용 정책은 구분합니다.

법선각 triangle cross product를 CAD normal과 비교합니다. solid는 법선 양쪽의 CAD 안/밖으로 바깥 방향을 확인하고 sheet는 지정 부호를 사용합니다. 반대 방향·모호한 방향은 오류입니다.
CAD 위 nodesurface의 모든 참조 node를 CAD로 투영해 이탈을 검사합니다. centroid 편차도 측정하지만 그것만으로 모든 곡면 편차를 확인하지는 않습니다.
면적·체적surface별 triangle 면적 합과 CAD 면적의 상대 차이, solid별 방향 있는 triangle 체적과 CAD 체적의 상대 차이를 측정합니다. 유한한 측정 증거를 요구하며 노드 개선의 비악화 조건으로 사용합니다. 현재 여기에는 보편적인 면적/체적 오차 통과 임계값이 따로 없습니다.
활성 CAD 편차곡률 제어가 활성인 경우 표본 편차/허용값이 1+1e−10을 넘으면 차단합니다. 이 조건은 AR·ICN 등의 형상 품질 기준 위반 경고와 다릅니다.

각 helper의 판정을 Inspection.issues로 모읍니다. Inspection.require_pass는 현재 코드에서 필수 issues를 검사하며 활성 형상 품질 기준 위반 수가 남았다는 이유만으로 NAS 발행을 막지 않습니다. 함수 이름만 보고 모든 품질 임계값을 강제한다고 해석하지 않아야 합니다.

노드 이동 개선: 후보·채택·복구

먼저 현재 메쉬를 검사하고 필수 오류가 없을 때만 개선을 시도합니다. improvement=false 또는 max_passes=0이면 이동을 시도하지 않습니다. 활성 형상 기준 위반 수가 0이면 개선 반복을 시작하지 않거나 즉시 끝냅니다. 모든 지표를 끈 상태에서 품질을 임의 종합 score로 높이는 별도 과정은 없습니다.

단계동작
후보 생성Relocate2D와 Laplace2D를 순서대로 번갈아 선택하여 대상 surface에 niter=1로 Gmsh optimize를 호출합니다. Relocate2D는 node relocation, Laplace2D는 이웃 node 관계를 사용하는 smoothing입니다. 세부 후보 좌표는 Gmsh가 계산합니다.
구조 고정node/element ID, connectivity, PID, surface와 entity 분류, 전체 요소·Physical Group 구성이 같은지 확인합니다. CAD point/curve에 속한 경계 node의 좌표와 parameter는 정확히 같아야 합니다.
필수 검사후보에 topology·법선·CAD·측정 검사를 다시 수행합니다. 기존 판정을 재사용하지 않습니다.
활성 품질 비악화활성 AR 최대값은 증가하지 않고 최소각·ICN·IGE·Radius Ratio의 최솟값은 감소하지 않아야 합니다. 비교에는 코드의 작은 수치 허용오차를 사용합니다.
개선 순위위반 요소 합집합 수가 줄거나, 같은 수에서 정해진 활성 지표 개선 조건을 만족해야 합니다. IGE·ICN 최소값 향상을 우선 확인하고 ICN이 비활성일 때 AR·최소각·Radius Ratio 향상 분기도 사용합니다. 비활성 지표 개선만으로 채택하지 않습니다.
크기·기하 비악화전역/국소 edge 요청비, 활성 CAD 편차비, 인접 크기비, CAD node/centroid 이탈, 면적·체적 상대 차이가 악화되지 않아야 합니다. 좌표 노이즈 및 상대 비교 허용오차를 반영합니다.
거부와 복구구조가 유지된 경우 저장한 전체 node 좌표·parameter를 복구하고 정확한 배열 일치와 필수 검사를 다시 확인합니다. 연결·분류를 되돌릴 수 없거나 정확한 rollback을 입증하지 못하면 발행을 차단합니다.
종료모든 활성 기준 통과, max_passes 도달, 같은 복구 상태에서 거부된 방법을 다시 시도할 상황이면 끝납니다. 거부 후 다른 방법은 시도할 수 있고 채택된 이동이 있으면 거부 기억을 초기화합니다.

이 개선은 연결을 고정한 노드 재배치입니다. edge swap, 새 node 추가, 삭제, 재삼각분할로 품질을 고치는 과정이 아닙니다. 따라서 경계 때문에 나쁜 triangle이 남을 수 있으며 현재 정책에서는 경고·보고서와 함께 발행할 수 있습니다.

선택적 품질 재시도와 재구성의 구분

quality_retry=delaunay는 새 생성 결과의 노드 개선 후에도 활성 품질 기준 위반이 남고, 해당 생성의 설정 Algorithm이 6인 경우에만 동작합니다. 필수 검사 실패나 생성 예외를 감추기 위한 catch-all 대체 알고리즘이 아닙니다.

재시도 전 CAD·크기장·생성 참조를 다시 확인한 뒤 이전 메쉬 전체를 지우고 요소·node가 남지 않았는지 검사합니다. 기존 곡률 보정 scale·표본 cache·실패 candidate ID를 재사용하지 않고 새 CurvaturePlan을 만듭니다. Algorithm 5로 한 번 생성한 뒤 곡면 편차 반복과 노드 개선을 다시 수행합니다. Algorithm 5의 품질이 항상 더 좋다는 보장은 없고 이후에도 기준 위반은 경고로 남을 수 있습니다.

구분바꾸는 것보존·대체 범위
CAD 재구성확정 설정으로 새 OCC model을 읽어 구성동일 원본 CAD의 단위·위상·면 대응을 확인합니다. 형상을 자동 수리한다는 뜻이 아닙니다.
곡면 편차 보정 재생성곡률 요청 scale/patch를 줄인 뒤 전체 메쉬 재생성CAD·크기장 설계는 유지하지만 메쉬 ID·연결·경계 분할은 다시 만들어질 수 있습니다.
품질 알고리즘 재시도Algorithm 6 → 5 및 곡률 계획 재초기화명시 요청 시 새 생성 작업에서 한 번. 이전 메쉬를 대체합니다.
노드 이동 개선surface 내부 node 좌표ID·connectivity·PID·entity·point/curve 경계 좌표/parameter를 보존합니다.

NAS·품질 보고서의 생성과 검증

발행 직전 snapshot과 현재 model 일치, CAD·field·경계·생성 참조를 확인하고 inspect_mesh를 다시 수행합니다. 로컬 임시 NAS를 배타 생성하고 자체 card 검사와 pyNastran 독립 읽기로 검증한 후 그 NAS 해시와 같은 메쉬 판정으로 HTML을 만듭니다.

출력 항목저장·검증 원리
GRIDnode ID와 output_unit 기준 x,y,z 좌표. 부동소수점 round-trip을 보존하는 실수 표현으로 저장하고 재읽은 좌표 배열의 정확한 일치를 검사합니다.
CTRIA3element ID, PID, 순서 있는 node ID 3개. node 순서에 법선 방향이 반영됩니다. PID는 CAD surface 대응이며 재료 물성이나 MoM 경계조건을 자동 정의하지 않습니다.
ENDDATA데이터 종료. 주석 외 미지원 card와 종료 뒤 데이터를 거부합니다. PSHELL·MAT1 등의 해석 물성 card를 생성하는 범위가 아닙니다.
독립 NAS 읽기pyNastran은 punch=True, xref=False로 읽고 ID·좌표·connectivity·PID·요소 종류를 현재 배열에 대조합니다. 물성 card가 없는 표면 전달 형식에 대해 xref를 수행하지 않는 계약입니다.
생성 참조주석의 provenance schema 5에 유효 설정·CAD 해시·소스 식별·버전·생성 옵션 등을 담습니다. 이전 schema를 현재 설정으로 몰래 변환하지 않습니다. 현재 actual_algorithm·actual_threads·improvement_history는 null입니다. configured_options를 실제 실행 추적으로 해석하지 않으며 EM 해석 결과를 담는 메타데이터도 아닙니다.
보고서 대응최종 NAS SHA-256과 CAD SHA-256, 설정 및 지표 요약을 담고 기준 위반 요소는 NAS element ID로 표시합니다. 비활성 지표는 평가하지 않음이며 위반 수는 지표 합집합입니다.
전송공통 엔진이 임시 출력 묶음을 확정한 뒤 변환기가 요청 NAS·대응 보고서를 해시 확인하며 최종 경로로 복사합니다. 기존 파일을 덮어쓰지 않고 실패 시 이번에 만든 파일만 정체성 확인 후 정리합니다.
파일 구조·기하·지표 측정의 검증과 전자기 해의 검증은 다릅니다. 실제 MoM 사용에서는 관심 관측량과 오차 정의를 정하고 메쉬·적분·기저/해석 설정에 따른 수렴을 별도로 확인해야 합니다.
