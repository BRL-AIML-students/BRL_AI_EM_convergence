# 검증 기록

검증일: 2026-09-30. 대상 환경: Windows x64, Python 3.12.14,
Gmsh 4.15.2, NumPy 1.26.4, pyNastran 1.4.1, uv 0.12.20.

## 확인한 내용

- 루트 `python -m pytest`: **25개 통과**. 기존 엔진 테스트와 UI 서버의
  생성·오류·CAD 경로·품질 실패·종료 처리 회귀 테스트를 포함합니다.
- Node.js의 `01_mesh_generator/tests/test_viewer_js.cjs`: NAS 파싱과
  파일에서 canvas로 이어지는 렌더링 테스트 통과.
- 기존 메시 엔진의 Python 소스 10개와 품질 프로필 1개를 원본과
  SHA-256으로 비교하여 모두 동일함을 확인했습니다.
- 실제 브라우저에서 판 메시를 생성하고 뷰어에 자동 표시했습니다
  (검증 사례: 노드 184개, 삼각형 318개, PID 1개).
- 실제 BREP CAD를 한글·공백이 포함된 경로에서 읽고 NAS를 생성했습니다.
- UI 종료, 잘못된 Origin/Host 거부, 세션 임시 파일 정리를 확인했습니다.
- Python 자동 준비를 포함한 새 가상환경 설치와 반복 설치가 성공했습니다.
- 별도의 한글·공백 경로에 소스만 복사하고, 이미 설치된 Python을
  `-PythonExecutable`로 지정하여 새 가상환경 설치를 확인했습니다.

## 범위와 한계

별도 복사본 설치는 같은 컴퓨터에서 수행했습니다. 다른 실제 컴퓨터의
장치·권한·보안 프로그램 차이는 별도 확인이 필요합니다. 대형 CAD/메시의
성능과 MoM 해석 정확도는 이번 이전 검증의 대상이 아닙니다.

`examples/unit_triangle_mm.nas`는 입력 형식 확인용 최소 예제이며,
전자기 해석 정확도를 검증하는 기준 문제는 아닙니다.

## 품질 게이트 v2 — 2026-10-01

같은 고정 의존성 환경에서 Python 테스트 **34개 통과**. 추가 사례는 분석식 AR와 스케일 변화, 납작한 요소 차단, 굽은 정합/비정합 접합, 의도적 갭/공차 내 모호 후보, 다른 ID의 일치 위치, 분리된 정점 fan, 열린/닫힌 성분 혼합, 탐색 예산 초과와 NAS 발행 보류를 포함합니다. 기존 CLI·브라우저·CAD·NAS 회귀도 통과했습니다.

임계값의 해석 교정과 MoM 연결은 수행하지 않았으며 사용자 요청 전까지 범위에서 제외합니다. 정점–모서리 기하 검사로 일반적인 삼각형 면 교차 부재를 보증하지 않습니다.
