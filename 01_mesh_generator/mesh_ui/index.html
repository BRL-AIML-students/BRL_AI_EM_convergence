BRL 표면 메시 생성기

형상 설정 → 파장·크기 제어 → NAS 확인

형상

t=0은 밑면이 열린 곡면, t>0은 벽 두께 솔리드입니다. 1차 삼각형 표면 메시를 생성합니다.

최소·최대 크기

곡률 제어·국소 field·추가 품질 개선을 제외하고 Gmsh 기본 알고리즘·smoothing을 사용합니다.
자동 계산 OFF 시 수동 값을 사용합니다. 일괄 비교에서는 자동 계산 ON이어도 수동 값을 baseline으로 사용합니다.

파장 고려

기존 국소 세분화 설정
비교 조건을 해제한 경우에만 적용됩니다. OFF에서도 작은 특징 기반 전역 크기 제어가 적용될 수 있습니다.
대기 중 · 목표 크기는 해석 정확도 보증이 아닙니다.
품질 게이트를 통과한 NAS만 발행합니다. 실패 시 출력 폴더의 diagnostic.msh와 보고서를 확인하세요.
