# BRL 표면 메시 생성기

이 폴더는 Gmsh 기반 1차 삼각형 표면 메시 생성기와 NAS 브라우저 뷰어를 포함합니다. 저장소 설치와 Python 환경 구성은 [루트 안내](../README.md)를 따르세요.

## 실행

루트에서 설치를 마친 뒤 `run_ui.bat`을 실행합니다. 브라우저 UI에서 기본 형상 또는 STEP/STP/IGES/IGS/BREP CAD 파일을 선택하고 단위와 메시 크기 조건을 입력할 수 있습니다. 완료된 NAS 메시가 오른쪽 뷰어에 표시됩니다. UI는 `127.0.0.1`에서만 실행되며 종료 버튼이나 콘솔의 Ctrl+C로 닫습니다.

Gmsh 기본 UI는 `run_gmsh_ui.bat`으로 실행합니다. ONELAB의 BRL 트리에서 형상 수치/CAD 파일과 기준을 지정하고 Action 1(생성), 2(검사), 3(개선), 4(발행), 5(종료)를 선택하세요. 선택적 JSON 설정을 실행 인수로 전달할 수 있습니다. 현재 메시의 수동 변경 후에는 다시 검사하며, 미통과 메시의 NAS는 발행하지 않습니다. 상세 계약은 [메시 인터페이스](../docs/mesh-interface.md#gmsh-기본-ui), 적용 기준과 참고문헌은 [메시 생성 기준](../docs/mesh-generation-guide.md)에 있습니다.

JSON 설정으로 실행하려면 이 폴더를 현재 위치로 두고 다음을 실행합니다.

```powershell
..\.venv\Scripts\python.exe -m geometry_mesh.cli examples\plate_wave_local.json
```

CLI의 설정 형식, NAS 카드, 보고서와 종료 코드는 [메시 인터페이스 문서](../docs/mesh-interface.md)에 있습니다.

## 파장 및 메시 크기

- 파장은 `λ = 299792458 / (f √(εr μr))` m로 계산합니다. `λ / 파장당 요소 수`는 전역 목표 크기의 상한으로 적용됩니다. 기본 상대 유전율과 투자율은 1이며, 기본 목표는 파장당 10요소입니다. 계산은 균질·무손실 매질의 위상 파장을 가정합니다. 분산·손실 매질이나 재료 경계별 파장은 다루지 않습니다.
- 전역 크기는 모델 bounding box 대각선과 `scale_fraction`을 바탕으로 하며, 파장 상한, 사용자 상한, 크기 하한, 요소 예산 정책의 영향을 받습니다. 국소 모드에서는 작은 특징이 전역 크기를 한꺼번에 줄이지 않습니다.
- 자동 국소 세분화는 곡선 길이 또는 `√면적`이 모델 크기 × `feature_threshold_fraction` 이하인 곡선·면을 대상으로 합니다. Gmsh `Distance`와 `Threshold` 필드로 특징 근처를 세분화하고 `transition_fraction` 거리에서 전역 크기로 되돌립니다.
- 직접 국소 세분화는 `mesh.local.boxes`에 상자 좌표와 목표 크기를 지정합니다. 상자 좌표와 크기는 출력 단위이며, 중첩 필드는 작은 크기를 적용합니다.

목표 크기는 모든 요소 변 길이의 엄격한 상한이 아닙니다. 파장당 10요소도 전자기 해석 정확도를 보증하지 않으므로, 재료와 형상, 모서리 특이성, 해법 차수에 맞춘 수렴 검사가 필요합니다. 정확한 표면 간격 자동 검출은 제공하지 않으며, 필요한 곳은 국소 상자로 지정하세요.

## NAS 뷰어

통합 UI에서 결과를 확인하거나 `viewer.html`을 열어 NAS 파일을 불러올 수 있습니다. 뷰어는 `GRID`, `GRID*`와 이어쓰기 줄, `CTRIA3`, `ENDDATA` 표면 메시를 표시합니다. 물성 카드, 셸 두께, 2차 요소와 체적 요소는 읽지 않습니다. 자세한 NAS 계약과 지원 범위는 [메시 인터페이스 문서](../docs/mesh-interface.md)를 참고하세요.
